# Fixing mistakes

Corrections go through Claude too. Say what's wrong in plain words:

| You say | What happens |
| --- | --- |
| "I sent Sarah the contact." | The promise is marked done. |
| "We gave Tom the hiking book." | The gift idea is marked settled. |
| "Sarah isn't at Siemens any more." | The fact is marked outdated; it leaves briefings but stays in the history. |
| "Her birthday is the 13th, not the 12th." | The item is edited. |
| "Anna was there too." / "Tom wasn't there after all." | Anna is added to the conversation; Tom is taken out of it. |
| "Make the thing about her father private." | Its visibility changes. |
| "Delete what I said about Lukas yesterday." | The item, or the whole conversation with its items, is deleted. |
| "Lu is Lukas Hoffmann." | "Lu" is added as an alias. |
| "Rename Oma Gerda to Gerda Becker." | The person is renamed. |
| "Sara and Sarah Klein are the same person." | The duplicate is merged into the other person. |
| "My partner can read that dinner's transcript." | The transcript is shared, once nothing in that conversation is private. |

You can edit or delete your own items and your partner's shared ones. Only whoever recorded an item changes its visibility, and only whoever recorded a conversation edits or deletes it.

Some fixes can also be done in the web app: on a person's page, each item has quick actions to mark it done, share it or delete it.
